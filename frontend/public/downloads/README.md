# Masaüstü kurulum dosyalarını buraya koyun

- Windows: `yarn pack:desktop:win` → `KilicCoffee-Setup.exe` (`NEXT_PUBLIC_DOWNLOAD_WINDOWS`)
- macOS: bir Mac’te `yarn pack:desktop:mac` → `KilicCoffee.dmg` (`NEXT_PUBLIC_DOWNLOAD_MAC=/downloads/KilicCoffee.dmg`)
- Linux: `yarn pack:desktop:linux` → `KilicCoffee.AppImage` / `KilicCoffee.deb` (`NEXT_PUBLIC_DOWNLOAD_LINUX=/downloads/KilicCoffee.AppImage`)

Android APK / mağaza linkleri: `NEXT_PUBLIC_DOWNLOAD_ANDROID`, `NEXT_PUBLIC_PLAY_STORE_URL`, `NEXT_PUBLIC_APP_STORE_URL`.
